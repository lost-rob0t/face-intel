* Authorized Scope
User requested file support across StarIntel Server APIs and an incoming-image
face pipeline with extraction, Person/candidate Relation emission, matching old
and incoming crops, and later evidence-backed confirmation by other actors.
Core schema 0.10.1 remains sole document authority. A dedicated bounded actor
owns pinned YuNet and SFace inference. Crops are core Pictures; tentative
identities are unnamed core Persons and related-to Relations with candidate
verificationStatus. Matching reuses Person records without merging identities.
Store model-specific vectors in core Picture metadata and query a bounded,
dataset-scoped gallery. Results expose truncation; scores are suggestions only.

* Reliability and Interfaces
HTTP and core Target process-image and register-face use the same actor.
Optional auto-processing acts after durable image upload. Deterministic run Targets
record completion only after graph writes; retries preserve reviewed records.
Rabbit consumes committed picture events, skips generated crops, and acknowledges
only after local durable processing and configured server delivery. Confirmation
requires explicit evidence-backed updates, never repeated similarity alone.
No arbitrary remote URL fetch or second file storage protocol.
