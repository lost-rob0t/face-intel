* Observed State and Scope
PR 2 (7f96b456) supplies face observations and candidate records, but no embeddings.
User requested implementation of the facial similarity engine while another agent
works on cropping. This branch builds on PR 2 without modifying its contract pin.
The crop interface accepts stored Picture IDs for already aligned 112x112 RGB
faces. Detection and landmark alignment remain the crop producer's responsibility.
OpenCV SFace is the initial backend; a narrow embedding interface permits replacement.

* Execution and Evaluation
A dedicated bounded actor owns the model. Model bytes must match an explicit SHA-256.
No automatic download or generated schema edit. Optional configuration advertises
comparison and ranking only when enabled. HTTP and Target share commands. Candidate
lists contain at most 100 distinct crop IDs; rank limit at most 100. Check propagated
deadlines between reads and inference calls. Return cosine scores in [-1,1], model
identity, and typed crop references; never label scores as probabilities or confirmed
identity. No Person mutation, automatic linking, embedding persistence, global scan,
or threshold-based identity decision is in this slice.
Regression checks cover scoring, ranking, actor ownership, auth, disabled mode,
invalid vectors/images, deadlines, and HTTP/Target parity. A real pinned model smoke
test checks inference; recognition accuracy requires separate representative data.
