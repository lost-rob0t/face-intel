* Inference

The service can progress independently of upstream branch promotion by consuming
an exact local generated dependency. A view keyed by dataset and normalized name
supports exact name/alias lookup without inventing a competing Person schema.
Explicit annotation relations can be queried independently from Person fields.

* Contradictions

Earlier conceptual examples used _id, schema_version, nested data, and untyped
references as public StarIntel objects. Those examples do not match this generated
contract. _id and _rev belong only in the CouchDB persistence adapter.

The earlier broader face-recognition design is not the implemented scope. This
foundation implements supplied Person data and explicit photo annotations only.
